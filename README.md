# ساخت APK بازی برج هانوی
1. در github.com یک مخزن (repository) جدید بسازید و همه‌ی فایل‌های این پوشه را (از جمله پوشه‌ی مخفی .github) در آن آپلود کنید.
2. به تب Actions بروید؛ اگر ساخت خودکار شروع نشد، «Build APK» را انتخاب و Run workflow بزنید.
3. بعد از ۵ تا ۱۰ دقیقه، در پایین صفحه‌ی اجرا، فایل hanoi-debug-apk را دانلود کنید. داخل آن app-debug.apk است.
4. فایل را روی گوشی اندروید نصب کنید (اجازه‌ی «نصب از منابع ناشناس» لازم است).
این نسخه آزمایشی (debug) است. برای انتشار در بازار باید نسخه‌ی release با کلید امضای خودتان ساخته شود.
بازی داخل www/index.html است و هر تغییر در آن، با push بعدی، APK جدید می‌سازد.
